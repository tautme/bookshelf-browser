# Bookshelf Browser

Tiny Express app that shows a random image from the `images/` folder on every page load.

## Run locally

```
npm install
npm start
```

Then open http://localhost:3000.

## Adding images

Drop `.jpg`, `.jpeg`, `.png`, `.gif`, or `.webp` files into the `images/` folder. No code changes needed — refresh the page to see a different one.
